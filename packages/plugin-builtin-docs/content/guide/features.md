# 功能介绍

按"在哪里、谁能用"过一遍全部功能。功能=插件，启停与配置都在「管理 → 插件管理」。

## 页面与写作

- **编辑与版本**：编辑后保存即产生版本；页面下方「历史版本」可对比与恢复
  （恢复要求页面管理权）。写法见 [[guide/markdown-demo|Markdown 演示]]。
- **层级与路径**：slug 用 `/` 分层（`guide/features`），权限沿层级继承收紧。
- **反链**：页面底部显示"谁引用了我"；链接写法见 [[guide/special-structures|特殊结构]] 的「Wikilink」。
- **草稿**：编辑器内容自动存草稿，换设备/换标签页不丢。
- **附件**：阅读页可管理附件；列表需要编辑权，删自己上传的不需要。

## 权限与协作

- **组织与角色**：owner / admin / member / viewer；admin 的"看到一切"会写入审计。
- **可见性**：private / org / public 三档 + 发布闸门；子页默认继承父级收紧。
- **显式授予与访问申请**：对够不着的页面可发起访问申请，由有管理权的人批准。
- **审计**：覆盖式访问、权限变更、插件启停均留痕。

## 检索

顶栏搜索框（或 `/search`）。中文按 trigram 匹配，支持整短语；结果只含你有权阅读的内容，
受限块的内容不会出现在摘要片段里。

## AI 能力

底部助手坞（或 `/ask`）。助手能：

1. **检索知识库并回答**（read_page / search_kb / list_pages）；
2. **代你写页面**（page.update，写前征得确认，产生正常版本历史）；
3. **翻页跳转**（open_page / scroll_to）；
4. **管理插件**（受护栏约束：不能把自己关到锁死状态）；
5. 每篇文章顶部自动生成的**摘要卡**（可手动重算）。

所有 AI 写操作进入**变更日志**，可按轮一键回退。

## 身份

- 注册 / 登录（用户名 + 密码），会话 cookie 维持；
- 可启用 **OIDC** 单点登录（插件管理里配置 issuer / client）。

## 插件管理

- 启停、改配置（表单即时校验、支持热更新）、看依赖与冲突组；
- 这些操作本身也有审计与 AI 回退护栏。
