# Markdown 语法参考

这一页是**源码 ↔ 效果**对照：每一节先给可直接复制的源码，紧接着给**同一条渲染管线**跑出来的真实效果（不是截图，也不是"你应该会看到"）。

管线是 `marked`（GitHub Flavored Markdown，开启 `breaks`）→ DOMPurify 消毒。本页正文就是它的输入，所以下面的"效果"你都能在这页里直接对照。

## 三条最常踩的坑

1. **单个换行就会断行**（GFM 的 `breaks`）。想把两行接成同一段，就写在同一个段落里、别换行——换了行就真的断。
2. **表格里的 `|` 必须写成 `\|`**，**包括行内代码里的**：想在单元格里显示 `a | b`，源码要写成反引号包起来的 `a \| b`（反斜杠在反引号**里面**）。写成裸 `|` 会把那一行撕成更多列。
3. **`---` 紧跟文字会变成"二级标题下划线"**（Setext 语法）。想画分隔线，前面先空一行。

## 标题

源码：

````md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

Setext 写法（文字下面画线：等号=一级、减号=二级）
一级标题
========
二级标题
--------
````

效果：

# 一级标题（示例）
## 二级标题（示例）
### 三级标题（示例）
#### 四级标题（示例）
##### 五级标题（示例）
###### 六级标题（示例）

Setext 一级（示例）
==================

Setext 二级（示例）
------------------

**锚点规则**（与 Docusaurus / VitePress 的默认口径一致）：

- **只有 h2–h3 生成锚点 id 并进入页内目录**；h1 是页面标题，故意不给 id；h4–h6 有 id 但不进目录。
- id 由标题文本推导：小写化、空白转 `-`、**保留中日韩文字**、丢掉标点与 emoji、连续 `-` 折叠；同名标题按出现顺序追加 `-1`、`-2`。
- 所以 `## 表格` 这一节的 id 就是 `表格`，写法是 `[跳到表格](#表格)` → [跳到表格](#表格)。
- 锚点链接会被改写成路由内锚点（`#/wiki/<slug>?a=<id>`），不会把整页 hash 弄乱。

## 段落与换行

源码：

```md
第一段。

第二段（用空行分段）。

这是同一段
但中间换了行——因为启用了 breaks，这里会断行。
```

效果：

第一段。

第二段（用空行分段）。

这是同一段
但中间换了行——因为启用了 breaks，这里会断行。

**为什么开 `breaks`**：写中文时"一句一行"更接近写作习惯，读 diff 也更清楚；关掉它就得在行尾补两个空格才肯断行，属于隐式约定。

## 表格

源码：

```md
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 甲 | 乙 | 1 |
| **粗体**也认 | `代码`也认 | 22 |
| 竖线要转义：`a \| b` | 空单元格也行 | |
```

效果：

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 甲 | 乙 | 1 |
| **粗体**也认 | `代码`也认 | 22 |
| 竖线要转义：`a \| b` | 空单元格也行 | |

- 对齐由分隔行的冒号位置决定：`:---` 左、`:---:` 中、`---:` 右。
- 表格**前面要有空行**；表格结束后也**要空一行**，否则下一行会被当作续行吞进表格。
- 单元格里只支持**行内**语法：不能放代码块、列表、引用这些块级内容。
- 需要在单元格里换行，用 `<br>`。

~~~

效果：

>

>

⚠️ **反例**：把 `---` 紧贴在文字下一行（文字、换行、`---`），它就不是分隔线，而是"把上面那行文字变成二级标题"的 Setext 下划线——也就是本页开头第三条坑。要演示这个陷阱，只能把它写进围栏代码里，否则页面自己就中招了。

## 链接

**外链**：直接写，点击新开标签页。

源码：

```md
[行内链接](https://example.com)
[带标题](https://example.com "悬停可见")
[引用式链接][ref]
<https://example.com>
裸链 https://example.com

[ref]: https://example.com
```

效果：

[行内链接](https://example.com)
[带标题](https://example.com "悬停可见")
[引用式链接][ref]
<https://example.com>
裸链 https://example.com

[ref]: https://example.com

**站内链接**有五种写法，推荐前两种：

- `[[guide/features]]` → [[guide/features]]（wikilink：自动显示目标页标题）
- `[[guide/features|想显示别的文字]]` → [[guide/features|想显示别的文字]]（显式文字，不再自动替换）
- `[文字](/guide/features)` → [文字](/guide/features)（站内绝对路径，归一化后进 wiki 路由）
- `[文字](guide/features)` → 相对路径：**只有目标页存在时才当站内链接**，否则原样保留（和文件名有歧义，不建议）
- `[文字](#表格)` → [文字](#表格)（同页锚点，跳到本页 id 为 `表格` 的标题）

规则与坑：

- **wikilink 的目标段不支持锚点**：目标里一旦出现 `#`，它和它后面的内容会被整段丢弃——不会跳到某一节。要跳章节，用上面的 `[文字](#章节 id)` 形态。
- 指向**不存在**的页面 → 红链：[[example/尚未创建的页面]]。红链是**入口不是错误**，点进去可以直接创建。
- 站内链接不会整页跳走：渲染时被改写成 `#/wiki/<slug>`，在当前单页应用里导航。
- 外链一律补 `target="_blank"` 与 `rel="noopener noreferrer"`；`mailto:` / `tel:` 交给系统处理。

## 图片与附件

源码：

```md
![外链图片](https://example.com/a.png "可选标题")
![站内附件](/api/attachments/<附件 id>)
```

效果（外链指向不存在的域名，会显示破图；站内附件必须先真实上传过）：

![外链图片](https://example.com/a.png "可选标题")

- **外链图片**用标准 `![替代文字](https://…)`，只在 http/https/相对路径下可用。
- **站内图片/文件**：在页面附件面板**上传**，编辑器会把返回的相对路径插进正文：`![文件名](/api/attachments/<id>)`。同源 cookie 自动带上，**权限跟页面走**：
  - 有权限 → 正常显示（懒加载）；
  - 无权限或文件已删 → 显示占位"此处附件无权访问或被删除"，旁边给「申请访问」入口；
  - 所以**别把附件 URL 当公开图床**贴到别处。
- 非图片文件用同一条路径，但写普通链接：`[报告.pdf](/api/attachments/<id>)`。

## 内联 HTML 与消毒

正文里的原始 HTML 会传给渲染器，但最终由 DOMPurify 按默认白名单过滤。实测可用的干净标签：

| 源码 | 效果 |
| --- | --- |
| `<kbd>Ctrl</kbd>` + `<kbd>S</kbd>` | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| `H<sub>2</sub>O`、`x<sup>2</sup>` | H<sub>2</sub>O、x<sup>2</sup> |
| `<mark>高亮</mark>` | <mark>高亮</mark> |
| `<abbr title="HyperText Markup Language">HTML</abbr>` | <abbr title="HyperText Markup Language">HTML</abbr> |
| `<details><summary>折叠标题</summary>折叠内容</details>` | <details><summary>折叠标题</summary>折叠内容</details> |

**会被剥掉**：`<script>`、`<iframe>`、事件属性（`onclick` 等）——这是消毒，不是 bug。

⚠️ 别用正文里的 HTML 去做**布局或配色**：那会绕开主题变量与设计系统守卫，换主题就散架。要排版请用 Markdown 结构（标题、列表、表格、引用）。

## 不支持清单

写之前先看一眼，免得白写：

| 写法 | 实际结果 |
| --- | --- |
| mermaid 图（用 mermaid 作语言名的围栏代码块） | 当普通代码块显示源码，不画图 |
| 公式 `$E=mc^2$`、`$$…$$` | 原样文字，不渲染 |
| 代码高亮 | 没有；语言名只写进 class |
| 脚注 `[^1]` 与 `[^1]: 定义` | 原样文字 |
| 定义列表（术语 + 缩进解释） | 不认，退化成普通段落 |
| `:smile:` 这类 emoji 短代码 | 原样文字（直接粘贴真 emoji 🙂 即可） |
| `==高亮==` | 原样文字（要高亮用 `<mark>`） |
| callout / admonition（`> [!NOTE]`） | 就是普通引用块，没有图标与配色 |
| 列布局 / 选项卡 / 分栏 | 没有；用标题 + 列表组织 |
| 目录宏 / 自动摘要标记 | 没有；页内目录由 h2–h3 自动生成 |

## 一个完整页面骨架

复制下面这段改一改，就是一篇结构完整、与主题一致的文章：

```md

一句话说清这页解决什么问题、给谁看。

## 背景

- 要点一
- 要点二

## 操作步骤

1. 第一步
2. 第二步

> 注意：这里是最容易踩的地方。

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 保存后没变化 | 内容未变时不产生新版本 |
| 搜不到 | 检查可见性与档位 |

## 参考

- [[guide/architecture|架构]]
- [外部资料](https://example.com)
```
