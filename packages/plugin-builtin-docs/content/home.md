# 欢迎使用 GeeWiki

GeeWiki 是一个 **AI 原生的团队知识库**：页面、权限、检索、编辑、AI 助手全部是插件，
引擎本身不含任何业务知识——这套文档本身也是以插件形式内置的。

## 三步上手

1. **注册并登录**（右上角）。未登录的访客只能看到 public 档且已发布的页面。
2. **打开任意页面点「编辑」**，保存即产生一个版本——旧正文自动进历史，可随时回看。
3. **用底部的 AI 助手**：它能检索知识库、代你写页面、跳转定位；它做的每一步写操作
   都记录在变更日志里，可以一键回退。详见 [[guide/features|功能介绍]] 的「AI 能力」。

## 默认规则（知道这几条就够了）

- 新建的页面默认**组织内可见**（`org`），同组织成员可编辑；公开到全网需要
  在「权限」里设为 public 并**发布**。
- 路径即层级：`guide/features` 是 `guide` 的孩子，**权限自动继承父级收紧**。
- 检索结果只包含你有权阅读的内容——命中层和正文层各过滤一次，不存在"搜到但打不开"的泄漏。

祝写作愉快。发现文档与软件行为不符，那一定是文档的错——欢迎在组织里反馈。
